SUTO PRODUÇÃO — Pasta de Deploy (Netlify)
==========================================

COMO COLOCAR NO AR:
1. Acesse https://app.netlify.com
2. Clique em "Add new site" > "Deploy manually"
3. Arraste ESTA PASTA INTEIRA (prod-deploy) para a área de upload
4. Aguarde o deploy. O site fica no ar num endereço .netlify.app
5. (Opcional) Site settings > Change site name -> escolha algo como "suto-producao"

IMPORTANTE — antes de usar:
- Rode o arquivo migration_producao.sql no Supabase (SQL Editor > Run).
  Isso cria as tabelas de produção (colaboradores, producao, avarias,
  devolucoes, config_producao). As demais tabelas do sistema não são afetadas.

CONTEÚDO DA PASTA:
- index.html      -> o sistema SUTO Produção
- manifest.json   -> configuração do app instalável (PWA)
- sw.js           -> service worker (offline) com cache isolado (prefixo sutoprod-)
- icons/          -> ícones do app (logo SUTO)
- _redirects      -> regra do Netlify para SPA

OBS: usa o projeto Supabase configurado em SB_URL_DEFAULT/SB_KEY_DEFAULT no
index.html. Os dados ficam isolados por empresa (org_id). Primeiro acesso
cria a conta da fábrica.
